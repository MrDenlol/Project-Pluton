# Проверка версии 0.1

Дата: 17 октября 2026 года. Среда: Windows x64, Rust 1.99.1.

Перед загрузкой исходников на GitHub выполнены:

- `cargo fmt --all -- --check` — форматирование проверено.
- `cargo check --locked --all-targets` — все цели компилируются.
- `cargo clippy --locked --all-targets -- -D warnings` — замечаний нет.
- `cargo test --locked --no-default-features` — 20 тестов ядра прошли.
- `cargo test --locked --all-targets` — 20 тестов прошли также с включённым GUI.

Тесты включают таблицы истинности, все пары 8-битных операндов,
10 000 случайных пар 64-битных операндов, границы разрядности, триггеры,
одновременный захват регистров, счётчик, АЛУ, JSON и ошибки соединений.

Предыдущая отладочная сборка графического приложения запускалась на Windows.
Проверка интерфейса была остановлена пользователем. Последующие изменения темы
и начального размера окна проверены компилятором; ручная проверка всех действий
редактора ещё не завершена. Готовый установщик или релизный EXE не публикуется.

В GitHub Actions предусмотрены проверки и сборка на Windows и Linux.
Их результат следует смотреть во вкладке Actions; наличие workflow само по себе
не подтверждает успешный прогон. macOS локально не проверялась.
