# План разработки Circuit Lab

Цель: открытая учебная программа на Rust с графическим редактором цифровых схем,
симуляцией триггеров и сумматоров, сохранением/загрузкой и рабочим 64-битным АЛУ.

## Этап 1. Требования и модель

- [x] Принять настольный интерфейс Rust + egui, лицензия MIT.
- [x] Описать блоки, именованные порты и шины 1–64 бит.
- [x] Версионировать JSON и валидировать файлы.
- [x] Зафиксировать беззнаковую арифметику и фронтовую модель памяти.

Приёмка: несовместимые порты, повторные источники, отсутствующие ID и
комбинационные петли отклоняются; обратная связь через регистр допускается.

## Этап 2. Ядро симуляции

- [x] Вентили AND / OR / XOR / NOT / NAND / NOR.
- [x] Полусумматор, полный сумматор и n-битный сумматор.
- [x] Вычитание, умножение, деление с остатком и мультиплексор.
- [x] D-, JK-, T-, SR-триггеры; общий генератор и синхронный захват.
- [x] Неизвестные сигналы, деление на ноль, недопустимое состояние SR.

Приёмка: таблицы истинности; исчерпывающая проверка 8-битной арифметики;
граничные и случайные 64-битные значения; захват только по фронту; отсутствие
гонок в цепочке двух регистров; счётчик с переполнением.

## Этап 3. Графический редактор

- [x] Библиотека, холст, перемещение, масштаб, соединение портов.
- [x] Инспектор входов/выходов, точный ввод u64, удаление элементов.
- [x] Шаг, запуск, пауза, сброс, временная диаграмма.
- [x] Отмена/повтор редактирования и защита несохранённых изменений.

Приёмка: собрать цепь вход → NOT → индикатор, поменять вход и увидеть
результат; удалить/восстановить блок; сохранить и снова открыть схему.

## Этап 4. Демонстрации и документация

- [x] АЛУ 64 бит: ADD / SUB / MUL / DIV → MUX → результат.
- [x] Полный сумматор из вентилей, набор триггеров, счётчик.
- [x] README с запуском, примерами и ограничениями модели.
- [x] MIT, инструкции для участников и CI.

Приёмка АЛУ: 42 и 7 дают 49 / 35 / 294 / 6 при кодах 0 / 1 / 2 / 3.
При нулевом делителе выбранное деление выдаёт DIV/0, сложение продолжает работать.
